# ✈️ Personalized Travel Itinerary Planner (GenAI Capstone Project)

An end-to-end AI-powered web application that generates personalized, day-by-day travel itineraries based on user preferences, duration, budget, and travel companions.

## 🚀 Features
- **Multimodal AI Integration:** Accepts destination preferences and user-uploaded reference images using Google Gemini 1.5 Flash.
- **Structured Schedules:** Detailed day-by-day itineraries covering morning, afternoon, and evening slots with local cuisine recommendations.
- **Budget Breakdown:** Itemized expense estimates tailored to backpacker, moderate, or luxury tier.
- **Interactive UI:** Built with Streamlit for seamless user experience and quick report downloads.

## 🛠️ Tech Stack
- **Frontend / App Framework:** Streamlit
- **AI Model / LLM:** Google Gemini 1.5 Flash via `google-generativeai`
- **Language:** Python 3.10+
- **Image Processing:** Pillow (PIL)
